## 二、产品概述

| 项 | 内容 |
|---|---|
| 小程序名称 | LEXY莱克 |
| AppID | `wx6bc687ff89875e20` |
| 产品定位 | 莱克品牌官方商城小程序（电商交易 + 会员运营 + 直播带货 + 门店连锁） |
| 包版本 | 目录版本 61；`userVersion 3.179.7.101`；运行环境 `env: prd` |
| 技术形态 | **有赞微商城（Youzan WSC）SaaS 模板实例化**，非自研代码 |

## 五、核心业务流程

### 5.1 主购物链路（P0）

```
首页装修页（dashboard）
   → 商品列表/搜索/分组（goods-list / shop/goods）
   → 商品详情（goods/detail，含秒杀/拼团/砍价活动态）
   → 加入购物车（goods/cart）
   → 确认订单（trade-buy/order/buy：地址、优惠券、积分、发票、自提）
   → 收银台（pay/unicashier：微信支付）
   → 订单结果（trade/order/result）
   → 订单列表/详情/退款（trade/order/list、refund/list）
```

### 5.2 直播带货链路（P0，品牌部重点）

```
视频号直播插件（live-player-plugin）进入直播间
   → 直播间挂载商品（goods/detail 半屏）
   → 秒杀组件（export seckill.js）在整点/限量场景抢购
   → 下单支付同 5.1
   → 观看-下单归因数据回流有赞 statcenter
```

### 5.3 会员运营链路（P1）

```
注册/登录（account/login，微信授权）
   → 领取/购买会员卡（membercard、levelcenter/plus 付费会员）
   → 消费得积分（point）→ 积分商城兑换（pointstore）
   → 领券用券（user/coupon、ump/coupon-pack）
   → 储值充值（pre-card）→ 权益卡（benefit-card）
   → 任务中心（user/task-center）签到/打卡（ump/sign-in、new-punch）
```

### 5.4 门店与连锁链路（P1）

```
定位授权（scope.userLocation）
   → 附近门店/门店列表（shop/chain-store、multi-store）
   → 门店选择（shop-select）
   → 到店自提地址（self-fetch-address）／门店核销（trade/cert/verify-ticket）
   → 门店导购接待（retail/chat、guide）
```

### 5.5 分销裂变链路（P2，可选开关）

```
分销员招募（salesman/salesman-center）→ 生成推广素材/朋友圈素材（zone/material、guide/pages/moments-material）
   → 分享商品/直播间（order/share、wxvideo/cps）
   → 成交佣金（salesman/report、rank、task-award）→ 提现
```

## 七、非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 采用异步分包（async-* / goods-core 等）把首屏主包控制在 2MB 内；`preloadRule` 预下载门店与会员分包；`onReachBottomDistance 400` 提前触底加载 |
| **可用性** | 统一错误页/停服页/空白页容器（packages/common），弱网降级到 H5（`wxh5-downgrade` 页面存在收银台 H5 降级链路） |
| **兼容** | 渲染层 `renderer: webview`（未启用 skyline），`componentFramework: exparser`，需兼容低版本基础库 |
| **安全合规** | `requiredPrivateInfos` + `__usePrivacyCheck__`：需在小程序后台配置隐私保护指引；位置权限需场景说明；支付走微信支付商户号 |
| **数据合规** | 电商类目需营业执照 + ICP 备案 +（如涉食品/医疗器械）相应资质；用户信息收集需明示 |
| **可运营** | 所有楼层/文案/活动均需后台可视化配置，禁止写死在前端 |

## 八、复刻实施路径（决策重点）

| 路径 | 说明 | 成本 | 与原版一致度 | 周期 | 建议 |
|---|---|---|---|---|---|
| **A. 微信小店（官方）** | 腾讯官方免费小店，原生打通视频号/ADQ | 低 | 中（功能子集，无积分/储值/分销） | 1–2 周 | 适合快速承接广告流量 |
| **B. 有赞 SaaS（原版同源）** | 开通有赞微商城 + 连锁版，配置即得 | 中（年费 + 交易费率） | **高（与现版同一框架）** | 2–4 周（主要是配置与素材） | **最推荐**，性价比最高 |
| **C. 自研小程序** | 参照本 PRD 自建前后端 | 高（研发 + 长期维护） | 取决于投入 | 3–6 个月起 | 仅在需要深度定制/数据私有化时选 |
| **D. 混合** | 微信小店承接广告 + 有赞承接会员运营 | 中 | — | 并行 | 可与 A/B 组合过渡 |

**推荐结论**：若目标是"复刻出一个能力对等的 LEXY莱克"，选 **B（有赞微商城·连锁版）**；若目标是"快速有一个能投 ADQ、能挂直播间的店"，选 **A（微信小店）**，后续再平滑升级到 B。

### 分阶段交付计划（以路径 B 为例）

| 阶段 | 周期 | 交付 |
|---|---|---|
| 阶段一 | 第 1–2 周 | 有赞店铺开通、类目资质与支付商户号、品牌主题（`#FF4444` 主色）、自定义 tabBar |
| 阶段二 | 第 3–4 周 | 首页装修（栏目按真机截图 1:1 复刻）、商品与分类录入、购物车/订单/支付联调 |
| 阶段三 | 第 5–6 周 | 视频号直播插件接入 + 秒杀配置、优惠券、客服 |
| 阶段四 | 第 7–8 周 | 会员/积分/门店连锁、隐私合规自查、上线 |

## 十、风险与提示
